# archie-agent 1.30.0

Released 2026-09-20. [All news](../index.md)

- The sandboxed runtime picks up line-anchored review comments: a finding is
  posted against the line it is about, with a suggested fix where it has one,
  and a suggestion is rejected unless it is single-line -- GitHub applies a
  multi-line suggestion only up to its first line, silently corrupting the
  file (#891).
- `diff_cap_lines` is an optional value in the shared config the runtime
  reconstructs, so an explicit `0` means "no cap" rather than being rewritten
  to the default. **Behaviour change** for a repo that set `0` expecting
  unlimited and was silently getting 400 (#899).
- A diff-cap park names a remedy that exists: a parked task's actions are
  retry, abandon and reject, so the reason no longer says "approve manually".
- A released container is not torn down twice -- the reaper no longer deletes
  teardown bookkeeping before `Release` is finished with it (#893).
- Build toolchain: `gofumpt` and `golangci-lint` are pinned as one matched
  pair, and `task fmt` uses the same engine the gate checks with, so the
  runtime's own gate is satisfiable (#901).
