The runtime carries a smaller, more focused set of changes than the same
version's archied entry: agent-side tool-result policy is now wired into the
worker's loop, MCP binary tool results survive to delivery, the container
`MaxUptime` lifetime cap is enforced with a timer, and a scheduled run records
completion so it does not re-fire each tick.

Note that several bullets above name config, webui and ratelimit packages. Those
are attributed here by the release tool's package-closure rule (`go list -deps`
over the agent binary), not because the agent owns them; the substantive
runtime changes are the worker, MCP, container and scheduling fixes.

This entry also confirms the removal of the dead `IncrementRetryCount` State
Store RPC, which the agent reaches through `staterpc` rather than by calling it
directly.
