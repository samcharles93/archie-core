# archie-agent 1.32.0

Released 2026-09-22. [All news](../index.md)

The sandboxed runtime links `storecontract` and `staterpc`, so it carries the dispatch-ledger
contract alongside archied:

- The shared `store.ErrAlreadyDispatched` sentinel now describes both dedup ledgers --
  `binding_dispatches` per `(binding_id, capture_id)`, and `playbook_dispatches` per
  `(playbook_id, playbook_version, event_id, action_id)`. Each is an at-most-once guarantee.
- `RecordPlaybookDispatch` is part of the store contract the runtime builds against.

archied and archie-agent move together in this release.
