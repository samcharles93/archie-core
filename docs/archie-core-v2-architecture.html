archie-core v2 Architecture

Daemon/agent split • NATS JetStream • Ephemeral Docker sandboxes • Yaegi core plugins • Skills-driven workflows

Daemon (archied)

  • • Poll forges for assigned/labelled issues
  • • Publish tasks to NATS JetStream
  • • Spawn ephemeral Docker containers per task
  • • Review agent responses before human delivery
  • • Manage persistent volumes with TTL
  • • Load core plugins at startup via Yaegi

Agent (archie-agent)

  • • Ephemeral Docker container, spawned per task
  • • Reads task.json from /data/ volume
  • • Runs routed workflow (implement / tdd / feasibility)
  • • Writes to response + system NATS channels
  • • Stays alive for grace period after completion
  • • Killed by daemon on terminal outcome or TTL

Extensibility Layers

  • • Skills: archie-wf-* SKILL.md (agentskills.io spec)
  • • Bundled plugins: Yaegi .go inside skill plugins/
  • • Core plugins: Yaegi .go in ~/.config/archie/plugins/
  • • Forges, ticketing, storage, vault, notify — all plugins
  • • File extension determines interpreter (.go = Yaegi)
  • • Volume plugins override worktree plugins on conflict
